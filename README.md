# Archivematica

The Archivematica plugin packages Omeka Classic static site exports and items as
[Archivematica](https://www.archivematica.org/) SIPs, and imports Archivematica DIPs
back into Omeka as items. Packaging static sites requires the
[Static Site Export](https://github.com/omeka/plugin-StaticSiteExport) plugin.
